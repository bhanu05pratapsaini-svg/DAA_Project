# Demonstration script

1. Build with make and launch ./smartpark.
2. Show the three synthetic parking bays and explain the typed record fields.
3. Reserve the nearest free bay for the sample driver, then try the same interval again to demonstrate conflict rejection.
4. Run the algorithm demo and point out merge sort, N-Queens and modular exponentiation.
5. Run the benchmark and explain that it currently measures only merge sort on a deterministic 2,000-element input.
6. Explain the normal, capacity-shock and stress scenarios from testing.md. Clearly label the latter two as planned experiments until generated and measured.

Do not present planned modules or unexecuted benchmarks as finished results.
