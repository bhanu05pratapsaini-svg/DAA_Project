# Smart Parking Allocation and Reservation Platform

C17 student project for Design and Analysis of Algorithms. Models parking bays, drivers, reservation windows and graph-routing exercises.

## Build

    make
    ./smartpark
    make test
    make clean

Requires Make and a C17 compiler.

## Included

Typed parking records, defensive validation, half-open reservation intervals, overlap rejection, nearest-coordinate allocation, sorting/searching exercises, maximum subarray, modular power, celebrity, activity selection, knapsack, LCS, subset sum, N-Queens, graph shortest paths, Prim, max flow, bipartite matching, a CLI and a merge-sort timing sample.

## Honest scope

This is a working starter, not the complete requested syllabus product. See docs/algorithm-map.md for exact status. Huffman, interval partitioning, Kruskal, matrix-chain, optimal BST, bounded TSP, branch-and-bound variants, CRT, optimized string matchers, Strassen, persistence/export and full scenario benchmarking remain to be completed and verified.

The bundled records are synthetic examples. No third-party dataset is included. Do not use this teaching simulator for real traffic or operational parking decisions; it has no live occupancy, payments, authentication, privacy controls or road-network integration.
